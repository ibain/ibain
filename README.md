# Ian Bain

Technical Program Manager working across developer platforms, CI/CD, cloud infrastructure, backend systems, automation, and AI-enabled workflows.

I tend to work where product, engineering, and operations overlap: identifying unclear technical problems, designing practical systems, building initial solutions, and helping teams ship reliably.

Most of my production work is in private company repositories. My public GitHub includes selected products, technical projects, and open-source contributions.

## Selected technical work

* **[Roomtone](https://github.com/ibain/roomtone)** - Built a local-first macOS meeting recorder with dual-track audio capture, offline transcription, speaker identification, optional local or cloud AI summaries, and transcript export. Built in Swift with a replaceable service architecture and privacy-first defaults.

* **[Jenkins Diversion SCM Plugin](https://plugins.jenkins.io/diversion-scm/)** ([GitHub source](https://github.com/jenkinsci/diversion-scm-plugin)) - Created and maintain the Jenkins SCM integration for Diversion, now hosted by the Jenkins project. Supports pipeline checkout, Global Pipeline Libraries, SCM polling, changelogs, authentication, and automated releases.

* **[Edison PTA content platform](https://github.com/ibain/weareedison-sanity)** - Built and maintain the content and integration layer behind a school PTA website, using Sanity, TypeScript, automated validation/deployment, and integrations with an existing Squarespace site.

* **Open-source integrations** - Contributing fixes and tests to projects including [Home Assistant Rivian](https://github.com/bretterer/home-assistant-rivian) and [NoLongerEvil SelfHosted](https://github.com/codykociemba/NoLongerEvil-SelfHosted), working across authentication, MQTT, Home Assistant discovery, device state, and integration behavior.
